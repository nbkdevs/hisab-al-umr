# Static age demo

A single offline page for a later Hugging Face upload. It is not deployed from this repository.

Open `index.html`. The script `age.js` is the npm library. Calculations stay in the browser.

The page links to [حساب العمر بالهجري والميلادي](https://hisabaleumr.com/).
