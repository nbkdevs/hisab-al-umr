# hisab-age-calculator

Ruby gem and CLI for [حساب العمر بالهجري والميلادي](https://hisabaleumr.com/).

```ruby
require "hisab_age_calculator"
result = HisabAgeCalculator.calculate("1990-05-15", as_of: "2026-11-08")
```

`homepage` and `homepage_uri` are `https://hisabaleumr.com/`. Tabular civil Hijri (Kuwaiti algorithm). A date can differ by ±1 day from crescent sighting and from Umm al-Qura. 29 February is observed on 1 March in a common year. This package is not published from this repository.
