# hisab-age-calculator

Python library and CLI for [حساب العمر بالهجري والميلادي](https://hisabaleumr.com/).

```python
from hisab_age_calculator import calculate_age
result = calculate_age("1990-05-15", as_of="2026-11-08")
```

```sh
hisab-age-calculator --birth 1990-05-15 --as-of 2026-11-08
```

`project.urls.Homepage` is `https://hisabaleumr.com/`. Tabular civil Hijri (Kuwaiti algorithm). A date can differ by ±1 day from crescent sighting and from Umm al-Qura. 29 February is observed on 1 March in a common year. This package is not published from this repository.
