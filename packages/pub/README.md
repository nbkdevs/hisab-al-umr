# hisab_age_calculator

Dart library and CLI for [حساب العمر بالهجري والميلادي](https://hisabaleumr.com/).

```dart
import 'package:hisab_age_calculator/hisab_age_calculator.dart';

final result = calculateAge('1990-05-15', asOf: '2026-11-08');
```

`homepage` in `pubspec.yaml` is `https://hisabaleumr.com/`. Tabular civil Hijri (Kuwaiti algorithm). A date can differ by ±1 day from crescent sighting and from Umm al-Qura. 29 February is observed on 1 March in a common year. This package is not published from this repository.
