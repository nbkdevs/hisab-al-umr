# Privacy

The libraries, command-line tools, static demo, and local API in this repository run offline.

- They do not open network connections.
- They do not send analytics.
- They do not write the birth date to disk.
- A date exists only in memory for the calculation you asked for.

The public website is a separate service. Its policy is [سياسة الخصوصية](https://hisabaleumr.com/سياسة-الخصوصية/).

The container already published as `iamnazzal/hisab-age-calculator` is also offline. It is not built or pushed from this checkout.
